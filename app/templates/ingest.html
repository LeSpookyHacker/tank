    Upload files or a folder

    Supports PDF, Markdown, DOCX, CSV, JSON, YAML, PNG/JPG. Pick individual files or an entire folder — categories are auto-detected from file names and content.

    Privacy notice: Images (PNG / JPG) are sent to the Anthropic API in their original form for AI-based text extraction. Internal hostnames, IP addresses, or other sensitive details visible in the image are transmitted before local redaction is applied.

    Local path

    Point at a file or directory already on this machine. Directories are walked recursively — categories are auto-detected. Useful when Tank is on a VM and the docs live on the same filesystem.

    Git repository

    Provide a local repo path. Tank reads manifests, CI, Dockerfile, grep hits and README — never raw source files. Privacy-safe by design.
